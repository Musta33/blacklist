# منظومة قائمة حظر المستأجرين (Tenant Blacklist System)

منظومة إدارية متكاملة وأمنة تم كتابتها بلغة Python مع إطار عمل Flask وتعتمد على قاعدة بيانات MongoDB عبر مكتبة pymongo.

## 🚀 المميزات الأساسية (Backend Capabilities)

1. **إدارة الاتصال بـ MongoDB**:
   - تهيئة المجموعات `users` و `blacklist`.
   - تطبيق `Unique Index` للبريد الإلكتروني لمنع تكرار الحسابات.

2. **تسجيل حساب جديد (`/api/auth/signup`)**:
   - تشفير كلمة المرور باستخدام `werkzeug.security` (generate_password_hash).
   - تعيين حالة الحساب تلقائياً كـ **`Pending`** (معلق بانتظار موافقة الإدارة).
   - الحساب الأول بالنظام يتم ترقيته تلقائياً كمدير مفعل لتسهيل التجربة الأولى.

3. **تسجيل الدخول (`/api/auth/login`)**:
   - التحقق من كلمة المشفرة.
   - منع الدخول تماماً إذا كانت حالة الحساب `Pending` وإظهار رسالة تنبيه للمستخدم.
   - حفظ بيانات المستخدم في الجلسة `session` عند القبول `Approved`.

4. **تسجيل الخروج (`/api/auth/logout`)**:
   - تنظيف الجلسة وتأمين الحساب.

5. **تفعيل الموافقة الإدارية (`/api/admin/approve`)**:
   - تمكين أدمن النظام من تغيير حالة أي حساب معلق إلى `Approved`.

6. **إدارة قائمة الحظر (`/api/blacklist`)**:
   - البحث والإضافة والعرض بحسب الهوية الوطنية، اسم المستأجر، أو رقم الهاتف.

## 🛠️ كيفية التشغيل المحلي (Local Run Instructions)

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. ضبط متغيرات البيئة `.env`
قم بإنشاء ملف `.env` وضبط القيم التالية:
```env
MONGO_URI=mongodb://localhost:27017/tenant_blacklist_db
SECRET_KEY=your_super_secret_key_here
```

### 3. تشغيل خادم Flask
```bash
python app.py
```
سيعمل الخادم على الرابط: `http://localhost:5000`
